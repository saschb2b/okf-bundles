# How an agent's context works

Everything else in this bundle is a consequence of this section.

- [The context window](context-window.md) - The finite space an agent reads before it answers, and the only place knowledge can reach a model.
- [Context assembly](context-assembly.md) - The step that decides what goes on the agent's desk each turn, and the highest-leverage part of an agent system.
- [The knowledge gap](knowledge-gap.md) - The difference between what a model learned from the public web and what is true inside your organization.
- [Scattered knowledge](scattered-knowledge.md) - Why organizational knowledge already exists but cannot be read by an agent: many surfaces, no shared shape.
- [Why standards win](why-standards-win.md) - Agreement beats technical superiority. OSI, Xanadu, Gopher, and Markdown each prove a piece of it, and each maps to an OKF design choice.
