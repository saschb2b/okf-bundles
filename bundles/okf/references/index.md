# References

The primary documents behind this bundle. The specification is normative, and the announcement supplies framing.

- [OKF v0.2 specification](okf-spec-v02.md) - The normative document: fourteen pages, Apache 2.0, published by Google Cloud on 24 July 2026. Carries a section-to-concept map.
- [Google Cloud, how the Open Knowledge Format can improve data sharing](google-cloud-announcement.md) - The announcement post that introduced OKF and framed it as a data-sharing problem.

Concepts outside the `spec/` and `trust/` layers cite the external work they rest on: the RAG paper for what retrieval is, "Lost in the Middle" for how position inside a context window affects recall, `agents.md` for the briefing-file convention, and the MCP and `llms.txt` specifications for the neighbouring layers.
